Setup, once

  1. Enable two APIs in your Google Cloud project: Google Search Console API and Google Analytics Data API.
  2. Create an OAuth client of type Web application, and add the origin shown above as both an authorized origin and a redirect URI.
  3. Paste the client ID above and hit Connect with Google.
  4. Fill the property fields — the Search Console picker fills itself once a token exists.
  5. Save, then open the Search Console and Analytics screens and turn off sample data.
i Google's endpoints are blocked in the shared artifact preview by its content-security policy. Run dashboard/index.html from a local server or your own host for live calls — the saved configuration and the whole interface work either way.
